Cap the frame rate

Uncapped, Spyro's movement breaks, and the in-game limiter is buggy too — so cap at 60 FPS in your graphics driver and leave the in-game limit off.

  • NVIDIA: Control Panel → Manage 3D settings → Program Settings → Spyro Reignited Trilogy → Max Frame Rate = 60 (on Linux, the same per-application profile in nvidia-settings).
  • AMD: Adrenalin → Gaming → Spyro Reignited Trilogy → Frame Rate Target Control = 60.
  • Linux (Proton): DXVK_FRAME_RATE=60 in the game's Steam launch options, or cap it with gamescope.

When checks are sent

Checks are read from your save file, so they reach the server when the game saves — finishing or quitting a level does it.
