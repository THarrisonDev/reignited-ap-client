# Reignited AP — Client

This is the client repo for [Reignited AP](https://github.com/THarrisonDev/reignited-ap),
the Archipelago implementation for Spyro Reignited Trilogy. It contains
everything that runs on the player's machine: a UE4SS Lua mod that bridges
the game, a Go daemon that scans game state, and a launcher that ties it all
together.

## Components

### `ue4ss_mod/`

The UE4SS Lua mod injected into the game.

- `srt_bridge/` — in-game bridge scripts: they connect to the Archipelago
  server, receive items, and report game state; they also start `checkd`
  (from the game's bridge folder) and ingest the checks it writes.
- `api/` — [`lua-apclientpp`](#acknowledgments), the Archipelago client
  library used to talk to the AP server.

### `checkd/`

A Go daemon that watches the game's save directory and scans for progress:
gems, orbs, skillpoints, Sparx levels, boss defeats, records, and Spyro 1/2/3
location checks. It writes detected checks to a shared drop directory (the
mod picks them up and reports them to the server) and maintains a heartbeat
file (`checkd.hb`) so the mod can dedupe its own spawns.

### `launcher/`

A small self-contained Go web server (UI built with htmx) that installs and
verifies the setup, edits the mod's `config.txt` (host/slot/password), and
launches the game via the `steam://` protocol handler. The installer copies the
mod, the save scanner, and (if missing) UE4SS v3.0.1 into place, enabled by the
**Install / update setup** button or the `-install` flag; the setup checks then
confirm the result. It also shows a read-only live feed of the slot's item
movements: it keeps its own listener-only connection to the Archipelago room.
It does not start `checkd` (the mod does), does not watch `checkd.hb`, and does
not forward checks — the mod's AP client reports checks itself.

## Getting Started

1. Download the latest client release from the parent repo's
   [Releases](https://github.com/THarrisonDev/reignited-ap/releases) page, or
   build the components from source (Go 1.26+ for `checkd` and `launcher`;
   [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS) for the mod).
2. Run `install.bat` (Windows) or `install.sh` (Linux) from the extracted
   release — or click **Install / update setup** in the launcher — to copy the
   mod, save scanner, and UE4SS into place.
3. Run the launcher and point it at your Spyro Reignited Trilogy installation;
   the setup checks confirm the install and save your connection settings.
4. Launch the game — the mod connects to the Archipelago server as usual.

## Development

Each Go component is its own module:

```sh
cd checkd   && go test ./...
cd launcher && go test ./...
```

`checkd` includes an extensive suite of tests backed by synthetic save
fixtures in `checkd/testdata` (generated by `checkd/scripts/gen_fixtures.py`,
never real player saves) covering gems, orbs, skillpoints, Sparx, bosses,
records, and 100% runs.

**Dependency policy:** keep third-party dependencies minimal. `checkd` is
stdlib-only (hence no `go.sum`); `launcher` currently needs only
`coder/websocket` for its UI feed. Prefer the stdlib or existing deps before
reaching for `go get` — every new dependency lands in both `go.mod` and the
release build, so it needs a reason.

## Contributing

Contributions are welcome! When working in this repo, keep components
independent: `checkd` and `launcher` should stay decoupled from the Lua mod
except through the drop directory contract (`checks.json` + `checkd.hb`).
